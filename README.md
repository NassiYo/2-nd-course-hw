# JavaScript Mini Games
A collection of six interactive mini-games built as part of my frontend development studies.
**Games:**
- Guess the Number
- Simple Arithmetic
- Reverse Text
- Rock, Paper, Scissors
- Quiz
- Random Color Generator

*Technologies: HTML5, CSS3, SCSS, JavaScript.*

Live Demo: [Play Mini Games](https://nassiyo.github.io/javascript-mini-games/) (available after deployment)
